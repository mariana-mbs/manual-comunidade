# Entre Plantões e Commits

Esta é uma comunidade fictícia para mulheres que estudam tecnologia enquanto conciliam trabalho, família e outras responsabilidades.

Aqui ninguém precisa fingir que sabe tudo. A ideia é dividir dúvidas, avanços, erros e oportunidades durante a transição de carreira.
